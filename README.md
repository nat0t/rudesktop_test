# Langton's Ant Simulation

Этот проект представляет собой симуляцию **Муравья Лэнгтона** — известного двумерного клеточного автомата с простыми правилами, но сложным и хаотичным поведением. Программа моделирует перемещение «муравья» по сетке, после чего визуализирует его траекторию и сохраняет результат в графический файл формата PNG.

## 🚀 Описание алгоритма

На каждом шаге симуляции муравей движется по клеткам поля, меняя их цвет по следующим правилам:
1. Если муравей находится на клетке базового цвета, он поворачивает на 90° в одну сторону, меняет цвет клетки и делает шаг вперед.
2. Если муравей находится на измененной клетке, он поворачивает на 90° в противоположную сторону, возвращает клетке исходный цвет и делает шаг вперед.
3. Симуляция завершается автоматически, когда муравей выходит за границы установленного поля.

В результате работы программа генерирует файл `ant_path.png`, отображающий финальный след («магистраль») муравья.

## 🛠 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd rudesktop_test
   ```

2. **Установите зависимости:**
   Для генерации изображений проект использует легковесную библиотеку `pypng`:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите симуляцию:**
   ```bash
   python main.py
   ```
   После завершения выполнения в корневой директории появится или обновится файл `ant_path.png`.

## ⚙️ Настройка (Конфигурация)

Вы можете изменить параметры симуляции в файле `config/config.py`. Доступные для редактирования константы:
* `FIELD_WIDTH` и `FIELD_HEIGHT` — размеры сетки.
* `ANT_START_X` и `ANT_START_Y` — начальные координаты муравья.
* `ANT_START_DIRECTION` — стартовое направление взгляда (вверх, вниз, влево, вправо).
* `FIELD_COLOR` — базовый цвет поля.
